# Security policy

Loopsmith runs on the pages you visit, so security problems matter even though it sends no data
anywhere.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/noahbds/loopsmith/security/advisories/new)
(the *Security* tab of the repository → *Report a vulnerability*).

Include what an attacker could do, on which site, and the steps to reproduce. You'll get an answer
as soon as possible; once a fix is released, the report can be made public with credit to you if
you like.

## Supported versions

Only the latest version published on the Chrome Web Store and Firefox Add-ons receives fixes.
